2. 提案内容の詳細

以下はメールの字句に基づく整理。金額や率などの数字はメールにあるものだけをそのまま載せている。

得られるもの（メール側の提示）

  • 有料の動画収録：Memrise のコースに出てくる単語・フレーズを読み上げる短い「Learn with Locals」クリップの作成を有料で依頼したい、という提案。フレーズは Memrise 側が提供し、クリップには名前が入る。※1本あたり・総額の金額はメールに記載なし
  • 学習者に見つけてもらう導線：メールによれば「過去1年で13万人（130,000 people）が Memrise で日本語を学んだ」。クリエイター向けにチューター・プロフィールと直接予約の仕組みを計画中。録画のみの参加の場合は、プロフィールから SNS チャンネルへリンクする形も検討できる、としている
  • 紹介コミッションの可能性：自分の経由で入った有料購読者に対する紹介コミッションがあり得る。ただし「詳細はまだ詰めているところ（We're still working out the details）」と明記されている

求められるもの（メール側の依頼）

  • 初回バッチ 約50本の録画：まず「around 50 very short clips（とても短いクリップ約50本）」を録る。録画の要件とサンプルは、承諾する前に共有されると書かれている
  • Memrise の宣伝協力（任意）：「もし Memrise を広めることに前向きなら（If you're open to promoting Memrise）」という条件付きで、チャンネルに合う形を相談したい、という位置づけ
  • クラス提供（任意）：Memrise 上でクラスを開くかどうかは選択制。開く場合、料金は自分で設定できる。Memrise 経由で予約されたクラスには30%のコミッション（提案値）がかかる
メール末尾の問いかけは「最初のクリップ収録に興味があるか（Would you be interested in recording a first set of clips for Memrise?）」。つまり最初の返信で求められているのは、まず録画への関心の有無。

3. Memriseという会社・サービス

  • 何のサービスか：実在のネイティブスピーカー本人が単語・フレーズを発話する短い動画を核にした言語学習アプリ。間隔反復（spaced repetition）による復習設計と組み合わせ、「実際にどう話すか」を聞いて覚える形式が特徴
  • 規模（公式About）：学習者は8,000万人超、利用は189か国、コースは149言語
  • 会社：2010年にロンドンで設立。創業者は Ed Cooke、Ben Whately、Greg Detre の3名（オックスフォードで神経科学・心理学を学んだ仲間）。公式Aboutによれば現在はロンドンの12名の小規模チーム
  • 今のプロダクト：語彙学習に加え、発音練習、AIとの会話練習、ポッドキャスト、試験対策などを持つ複合型アプリに広がっている。2017年に Google Play Awards の 'best app' を受賞
  • ビジネスモデル：アプリの無料利用＋有料サブスクリプション（Pro）型。今回の打診にある「有料購読者への紹介コミッション」はこの購読モデルの上に乗る話

「Learn with Locals」の位置づけ

Memrise の公式コースで、単語・フレーズごとに現地の話者本人が発話する動画クリップが付く仕組みの呼び名。今回の打診は、そのクリップの「話者」として参加し、名前入りで出演する話にあたる。チューター・プロフィールや直接予約は、メールの中で「計画中（We're planning）」とされており、始まっている機能ではなく今後の構想として提示されている。

4. 判断の論点

  • 論点1録画のみか、クラス提供まで含めるか：メール上、録画のみの参加も成立する形になっている（その場合はプロフィールから SNS へリンクする案）。クラス提供は任意の追加で、やる場合だけ30%コミッションの話が出てくる
  • 論点230%コミッションの範囲：かかるのは「Memrise 経由で予約されたクラス」だけ、という書き方。料金設定は自分でできる。既存の italki や自社サイトなど、Memrise の外の予約には触れていない
  • 論点3約50本の録画負担と、まだ見えない条件：クリップは「とても短い」もの約50本で、フレーズは先方提供。要件とサンプルは承諾前に共有される約束になっている。一方で報酬額がメールに書かれていないため、負担と条件の釣り合いは金額を確認するまで判断できない
  • 論点4名前入りの扱い：クリップには名前が入る。Anime Sensei としての露出になる反面、動画の使われ方（掲載範囲・期間・二次利用の可否）はメールに書かれていない
  • 論点5紹介コミッションは未確定：率も条件も「詳細は検討中」のため、現時点では判断材料に入れられない
  • 論点6急ぎではない：返信期限の指定はない。最初の返信は「録画への興味の有無」を聞く段階で、条件の詳細（金額・要件）はその先のやり取りで出てくる構造
