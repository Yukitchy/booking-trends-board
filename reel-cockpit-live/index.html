触れるプロトタイプ5案

前回の静止画ボードの5案を、実際にタップして動かせるプロトタイプに作り替えた版。各案ともスマホ幅に揃えた端末枠の中で、そのまま操作できる。スマホでは「全画面で開く」から実機サイズでも触れる。

試し方（全案共通の流れ）

  1. 管理画面でカレンダーの日付かプロジェクトカードをタップ → その回の編集画面へ
  2. 型ライブラリから型を選ぶ → プレビューに即反映（フック文・カット割りが変わる）
  3. 自動編集ボタンを押す → プログレスが走ってプレビューが再生される
  4. 微調整でフック文・フィルタ・カット間隔・速度を変える → その場で反映
  5. 書き出し → 完了表示まで。戻る導線で管理画面へ
